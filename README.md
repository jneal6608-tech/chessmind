# ChessMind

A personal chess coach that runs entirely in the browser. It plays you with
Stockfish-powered opponents, analyses every game, works out *why* you lose
(recurring weaknesses, with confidence levels), builds training from your own
mistakes, and measures whether you are actually improving.

Works on desktop, mobile and Chromebooks. No server, no account, no paid API.
All data stays in the browser's IndexedDB (export/import backups in Settings).

## Run it

Requires Node 20+.

```bash
npm install
npm run dev        # http://localhost:5173
```

```bash
npm test           # unit + engine integration tests (Stockfish runs in Node)
npm run build      # production build in dist/
npm run preview    # serve the build at http://localhost:4173
```

`npm run dev` / `npm run build` copy the Stockfish WebAssembly engine from
`node_modules/stockfish` into `public/engine/` first (`scripts/copy-engine.mjs`).

## Deploy

The build is a static site (`dist/`) with relative paths and hash routing, so it
works on any static host and in sub-folders, with no rewrite rules.

- **Netlify:** connect the repo, set the base directory to `chessmind/` (if it
  lives in a sub-folder); `netlify.toml` supplies the build command and output.
- **Vercel:** import the repo, set the root directory to `chessmind/`;
  `vercel.json` supplies the rest.
- **Anything else:** `npm run build`, upload `dist/`.

The engine is the single-threaded "lite" Stockfish 19 build, so no special
headers (COOP/COEP) are needed.

## What is in it

| Area | Where |
|---|---|
| Rules, SEE, pawn structure, phase | `src/chess/util.ts` (on top of chess.js) |
| Tactical pattern detection (fork, pin, skewer, discovered attack, hanging piece, back-rank mate…) | `src/chess/motifs.ts` |
| Stockfish UCI client (browser worker / Node process) | `src/engine/uci.ts`, `browser.ts`, `node.ts` |
| Opponent levels and personalities | `src/engine/opponent.ts` |
| Game review: evals, classification, accuracy, critical moments, phases, lessons | `src/analysis/review.ts` |
| Weakness classifier (cause of each mistake + confidence) | `src/analysis/classify.ts` |
| Weakness profile (recurring / developing / improving / one-time, priorities) | `src/analysis/profile.ts` |
| Strength estimate (separate from real ratings) and weekly report | `src/analysis/strength.ts`, `weekly.ts` |
| Exercises from your games, selection, spaced repetition, daily plan | `src/training/*` |
| Coach: explanations, built-in Q&A, optional Claude | `src/coach/*` |
| Persistence (IndexedDB), backups | `src/store/*` |
| Screens | `src/pages/*`, `src/ui/*` |
| Data: repertoire courses, theory endgames, opening names, exercise bank | `src/data/*` |

### How mistakes are classified
For each of your inaccuracies, mistakes, blunders and missed wins the reviewer
looks at: tactical patterns in the engine's best line (what you missed), patterns
in the opponent's best reply (what you allowed), whether the threat already existed
before your move (a "null move" search), static exchange evaluation (did you leave
something hanging or start a losing exchange), structural changes (pawn shield,
doubled/isolated pawns, knight on the rim, passive retreats), opening principles
(early queen, moving a piece twice, flank pawns), endgame features (king activity,
passed pawns, conversion of winning positions) and time spent on the move. Each
cause gets a confidence; when no rule explains the engine's preference the cause
is marked as uncertain instead of guessed.

### Opponents
Weaker levels search less deeply and may choose among near-best moves (and
occasionally decide from a very shallow search), so their mistakes are the kind
humans make: missing a tactic two or three moves deep. Personalities re-rank only
moves that are already acceptable for the level. The Master level is plain
Stockfish with the chosen thinking time. Level ratings are approximate guides,
not calibrated against human rating pools.

### Exercise bank
`src/data/puzzles.json` is generated by `scripts/gen-puzzles.ts` (engine
self-play with human-like oversights; every position checked at depth 12 and 16
for a unique solution) and merged by `scripts/merge-puzzles.ts`. Regenerate with:

```bash
npx tsx scripts/gen-puzzles.ts 1 200 data-src/gen/p1.json
npx tsx scripts/merge-puzzles.ts
```

### Optional Claude coach
In Settings you can add an Anthropic API key. The AI Coach then answers free-form
questions with Claude, which must call the local Stockfish tools for every
evaluation. Without a key the built-in coach answers from Stockfish directly
(best move, threats, plans, "is this move good?"). The key is stored only in
the browser and sent only to `api.anthropic.com`.

## Tests

`npm test` runs 86 tests (Vitest, Stockfish running in Node):

- **Rules** (`tests/rules.test.ts`): legal destinations, pins, castling (both
  sides, through/out of check, lost rights), en passant (and its expiry),
  promotion incl. under-promotion and capture-promotion, checkmate, stalemate,
  threefold repetition, insufficient material, static exchange evaluation,
  position sanity checks.
- **Patterns** (`tests/motifs.test.ts`): forks, pins, skewers, discovered
  attacks, hanging pieces, mates, back-rank mate vs. other mates.
- **Engine** (`tests/engine.test.ts`): start-up, mate detection, MultiPV,
  cancellation, termination and restart, every level and personality.
- **Analysis** (`tests/analysis.test.ts`): classification, causes and confidence
  on real games, recurring vs one-time weaknesses, strength estimate, exercises
  from your own mistakes, built-in coach answers.
- **Training** (`tests/training.test.ts`): spaced repetition, adaptive theme
  ratings, exercise selection order.
- **Persistence & import** (`tests/store.test.ts`): IndexedDB round trip,
  backup export/import (API key excluded), PGN parsing with clock times.
- **Data** (`tests/data.test.ts`): every repertoire line is legal, every theory
  endgame has the verdict we teach (checked by Stockfish at depth 22), every bank
  exercise has a legal solution.

Browser flows were checked with Playwright: playing full games (click and
drag), illegal moves, takebacks, reload persistence, checkmate, resign,
promotion, review walkthrough, PGN import, exercise solving and hints, endgame
play-outs vs Stockfish, the coach, opening practice, and layouts at phone width.

## Known limitations

- **Opponent ratings are approximate.** Levels are tuned by search depth and
  move choice, not calibrated against human players.
- **The strength estimate is ChessMind's own number** from results against its
  opponents (and rated imported games). It is shown next to, never in place of,
  your real ratings.
- **Cause classification is heuristic.** Each cause carries a confidence; low
  confidence is shown as such.
- **The exercise bank is modest** (about 650 positions plus 13 theory endgames), weighted toward
  material-winning tactics and defence; mates and skewers are fewer. Your own
  games add exercises continuously, and the generator can be run longer.
- **Lichess / Chess.com import** uses their public APIs from the browser; it
  could not be tested from the build sandbox (no network access to those
  sites). PGN paste/file import is fully tested.
- **The Claude coach** is optional and was not tested live (no API key in the
  build environment). The browser holds the key, which is only appropriate for
  a personal, single-user install.
- **Analysis depth** defaults to 12 for speed on Chromebooks; deeper settings
  are available but slower.
